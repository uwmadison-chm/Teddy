# Teddy Project

This is the open source repository for the Teddy Project.

There are three major directories in this repository, split between two projects.

## Teddy V1

This version of Teddy is a native mobile app, created in React Native, along with its coinciding backend server created using Django. It is the first iteration of Teddy, and it is the version used in the BeWell study.

[Teddy V1 React Native App](v1/teddyReactNative)

[Teddy V1 Django Backend](v1/teddyDjango)

## Teddy V2

This is the second, updated version of Teddy, completely redesigned as a React webpage with a Django backend. Unless you specifically wish to replicate the BeWell results exactly, we highly recommend you use this version. It is more modularized, as more features, and it's much easier to use since it's web-only.

[Teddy V2 Project](v2/TeddyWeb)
